# DealFlow CRM

A private, single-seat CRM + dialer that replaces Mojo Dialer and Mojo CRM for a solo NYC Douglas Elliman broker.

Built as four parallel slices — Core Data (A), Telephony (B), Compliance (C), and Communications (D) — on top of a shared Next.js 16 / Prisma / PostgreSQL shell.

Greenfield sibling to `dealflow-inbox-intelligence/`; that repo stays running and untouched.
